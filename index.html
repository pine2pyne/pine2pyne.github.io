TradingView community strategies, running offline in Python

Public trading strategies exist mostly as Pine Script, so their backtests run only inside a TradingView chart. The pynecore-strategies repository collects the open-source Pine strategies and indicators that PyneSys verified against TradingView and compiles them into PyneCore scripts. PyneCore executes Pine-style code bar by bar in Python, with the same series history, na handling, broker emulator and drawing objects, so every strategy becomes a command that backtests on any candles you have and writes its trades and statistics to CSV files.

The scripts can be backtested on any market, including exchanges that TradingView does not list, batch-tested from Python, or fed to a feature pipeline or an LLM agent. The repository is part of the open-source tooling of TheOneTrade.

Run a converted script

Requires Python 3.11+ and uv. The repository already contains every compiled script and library.

git clone https://github.com/theonetrade/pynecore-strategies.git
cd pynecore-strategies
uv sync --python 3.13          # installs pynesys-pynecore[cli,ccxt] into .venv

Download candles once. The .ohlcv file in data/ is a cache: later downloads append only new bars, and every run reads the file offline. Any exchange supported by CCXT works.

uv run pyne data download ccxt:GATE:BTC/USDT@60 --from 2025-09-25

Backtest a strategy or run an indicator. A file you converted above goes into scripts/ the same way.

export PYNE_NO_LOGO=1
uv run pyne run strategy_macd_reloaded_strategy_VO6DY8s1 ccxt_GATE_BTC_USDT_60
uv run pyne run indicator_supertrend_r6dAP7yi ccxt_GATE_BTC_USDT_60
uv run pyne run strategy_macd_reloaded_strategy_VO6DY8s1 ccxt_GATE_BTC_USDT_60 --from 2026-08-07 --to 2026-11-07

Higher and lower timeframes

Scripts that call request.security need a data file for every timeframe they request. List what a script needs, download it and pass it with --security.

uv run pyne run strategy_ict_master_suite_trading_iq_ABYnIcdl ccxt_GATE_BTC_USDT_60 --list-data
uv run pyne data download ccxt:GATE:BTC/USDT@1D --from 2021-01-01
uv run pyne run strategy_ict_master_suite_trading_iq_ABYnIcdl ccxt_GATE_BTC_USDT_60 --security "1D=ccxt_GATE_BTC_USDT_1D"

scripts/<script>.tomlEvery input and strategy setting. Uncomment a value to change it without editing code

Test run

PyneCore 6.12.1, Python 3.13. All 1,005 sources compiled, and every compiled file passed a Python syntax check. Each strategy was backtested on Gate.io BTC/USDT from 2026-08-07 to 2026-11-07 at 15m, 1h and 4h, with daily and weekly files supplied for request.security.
